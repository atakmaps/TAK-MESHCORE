# TAK-MESHCORE (MeshCore ATAK Plugin)

## This project is no longer supported

TAK-MESHCORE is **no longer supported or maintained**. It will not receive fixes, updates, or new releases.

## Use UV-CORE instead

MeshCore support now lives in the **UV-CORE** ATAK plugin. UV-CORE works with MeshCore, UV-PRO, or both radios (selected with the plugin's Radios setting).

- Repository: https://github.com/atakmaps/TAK-UV-CORE
- Releases: https://github.com/atakmaps/TAK-UV-CORE/releases
- Updates are also delivered through the ATAK update server.

The previous README and all of the code remain available in this repository's git history.
